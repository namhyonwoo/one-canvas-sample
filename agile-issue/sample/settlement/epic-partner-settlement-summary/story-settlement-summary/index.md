# 유저 스토리: settlement-summary (파트너가 이번 달 정산 현황을 요약해서 확인한다)

## User Story
파트너가 목록을 일일이 훑지 않고도 정산 상황을 한눈에 파악하기 위해, 기간별 정산 총액과 처리 현황을 요약 대시보드로 확인한다.

> 기획 출처: `epic-partner-settlement-summary` 참조 (캔버스 파일 경로는 에픽이 단일 출처)
> 대상 화면: 화면 1 `settlement-summary (정산 요약 대시보드)` — 번호 영역 ①(기간 탭), ②(정산 예정 금액), ③(처리 완료율), ④(상태별 건수), ⑤(정산 추이 — 디자인 시스템 미보유)
> **구현 전 필수**: 위 화면을 캔버스에서 열어 배치·컴포넌트 태깅(story id)을 확인한다.
> 앵커·Figma 시안은 `epic-partner-settlement-summary/index.md` 「참조 자료」에 있다 — 이 스토리는 배치·story id를 소유하지 않는다.

## 기능 정책

### 기간 탭 (①)
- **이번달 / 전월 / 전분기** 3종을 제공한다. 컴포넌트: `navigation/segmentedTabs`.
- 화면 진입 시 기본 선택은 **이번달**이다.
- 탭을 전환하면 아래 카드 3종(②③④)이 **함께 갱신**된다. 일부만 갱신되지 않는다.
- 탭을 연속으로 전환한 경우 **마지막으로 선택한 탭의 결과만** 화면에 반영한다. 먼저 보낸 요청의 응답이 나중에 도착해도 그 값으로 덮어쓰지 않는다.
- 요약 대시보드의 기간 탭은 정산 내역 목록의 조회 조건(기간·상태 필터)과 **독립적**이다. 서로 영향을 주지 않는다 — 목록 조회는 `epic-partner-settlement-list` 소유.

### 정산 예정 금액 (②)
- 선택한 기간 동안 파트너에게 지급될 **정산 예정 총액**. 컴포넌트: `layout/card`.

### 처리 완료율 (③)
- `완료 건수 ÷ 전체 건수`를 백분율로 표시한다. 컴포넌트: `display/progressBar`.
- 게이지 채움 비율과 옆의 `%` 텍스트가 항상 동일한 값을 가리킨다.

### 상태별 건수 (④)
- **완료 / 대기 / 보류** 3개를 각각 `{상태명} {n}건` 형식의 태그로 표시한다. 컴포넌트: `display/tag`.
- 건수가 `0`인 상태도 **태그를 숨기지 않고 `0건`으로 표시**한다 (캔버스 전월 데이터: 완료 12건 / 대기 0건 / 보류 0건).
- 세 태그의 건수 합은 처리 완료율 계산의 전체 건수와 일치한다.

### 정산 추이 (⑤) — 이 스토리 범위 밖
- 최근 6개월 정산 예정 금액 추이를 미니 라인 차트로 보여주는 영역이다.
- 필요한 컴포넌트 **TrendSparkline**이 `design-system/admin-partner`에 없어 **디자인 시스템 미보유(`신규 필요`)** 상태다.
- 디자인 시스템 작업은 애자일 이슈의 태스크 범위가 아니고(agile-issue-rule.md 「태스크 범위에서 제외되는 작업 — 디자인 시스템」), 이 항목은 분류가 **`신규 필요`** — 대체할 컴포넌트가 어디에도 없다. 그래서 이 영역은 **수락 기준·태스크·테스트를 두지 않는다.** 디자인 시스템 트랙에서 컴포넌트가 확정된 뒤 별도 스토리로 다룬다.

> 정산 상태 3종 정의·디자인 시스템 미보유 항목 처리: `epic-partner-settlement-summary/index.md` 참조 · 금액 표기 규칙: `settlement/index.md` 참조

### 열린 질문 (기획 확인 필요)
- 선택한 기간에 정산 데이터가 **한 건도 없을 때** 카드 3종의 표기(`0원` / `0%` / 전부 `0건` 인지, 별도 안내를 띄우는지)가 캔버스에 정의되어 있지 않다. 확정 후 AC·테스트를 보강한다.
- `전분기` 의 기준 구간(직전 분기 3개월 vs 직전 완료 분기) 정의가 캔버스에 없다. 확정 필요.

## 수락 기준 (Acceptance Criteria)
> Given-When-Then 시나리오로 작성한다. 정상/예외 등 조건 분기는 시나리오를 분리한다.

- [ ] **AC1** Given 이번 달 정산 데이터가 있는 파트너가 조회 화면에 접속했고, When 요약 영역을 확인하면, Then 이번 달 정산 예정 총액·처리 완료율·상태별 건수가 한눈에 요약되어 표시된다.
- [ ] **AC2** (보강) Given 파트너가 화면에 처음 진입했고, When 기간 탭을 확인하면, Then `이번달` 탭이 활성 상태다.
- [ ] **AC3** (보강) Given `이번달` 탭이 활성인 상태에서, When `전월` 탭을 클릭하면, Then 활성 표시가 `전월`로 이동하고 정산 예정 금액·처리 완료율·상태별 건수 3개 카드가 모두 전월 기준으로 갱신된다.
- [ ] **AC4** (보강) Given `전월` 탭이 활성인 상태에서, When `전분기` 탭을 클릭하면, Then 3개 카드가 모두 전분기 기준으로 갱신된다.
- [ ] **AC5** (보강) Given 어떤 기간이 선택되어 있고, When 처리 완료율 카드를 확인하면, Then 게이지 채움 비율과 옆의 `%` 텍스트가 동일한 값을 가리킨다.
- [ ] **AC6** (보강) Given 선택한 기간의 전체 정산 건이 모두 완료 처리되었고, When 처리 완료율 카드를 확인하면, Then 완료율이 `100%`이고 게이지가 가득 찬 상태로 표시된다.
- [ ] **AC7** (보강) Given 선택한 기간에 대기·보류 건이 하나도 없고, When 상태별 건수 카드를 확인하면, Then `대기 0건`, `보류 0건` 태그가 숨겨지지 않고 그대로 표시된다.
- [ ] **AC8** (보강) Given 선택한 기간의 요약이 표시되어 있고, When 상태별 건수 합계와 처리 완료율의 분모를 비교하면, Then 두 값이 일치한다.
- [ ] **AC9** (보강) Given 정산 예정 금액 카드가 표시되어 있고, When 금액 표기를 확인하면, Then 천 단위 콤마 + `원` 형식으로 표기된다.
- [ ] **AC10** (보강) Given 요약 대시보드에서 기간 탭을 전환했고, When 정산 내역 목록 화면(`epic-partner-settlement-list`)을 확인하면, Then 목록의 조회 조건과 결과는 영향을 받지 않고 그대로 유지된다.
- [ ] **AC11** (보강) Given 기간 탭을 연속으로 여러 번 전환했고, When 먼저 보낸 요청의 응답이 나중에 도착하면, Then 마지막으로 선택한 탭 기준 값만 표시되고 지연 응답으로 덮어써지지 않는다.

## 테스트 (QA Role)

### 성공
- 이번 달 정산 데이터가 있는 파트너로 접속 → 정산 예정 금액·처리 완료율·상태별 건수가 모두 표시된다. (AC1)
- 첫 진입 시 `이번달` 탭이 활성 상태다. (AC2)
- `전월` 탭 클릭 → 활성 표시가 이동하고 금액·완료율·건수 3개 카드가 모두 전월 값으로 바뀐다. (AC3)
- `전분기` 탭 클릭 → 3개 카드가 모두 전분기 값으로 바뀐다. (AC4)
- 완료율 `72%`일 때 게이지가 72% 지점까지 채워져 있고 텍스트도 `72%`다. (AC5)
- 전월(완료 12건 / 대기 0건 / 보류 0건) 선택 → 완료율 `100%`, 게이지가 가득 찬다. (AC6)
- 전월 선택 시 `대기 0건`, `보류 0건` 태그가 화면에 그대로 보인다. (AC7)
- 이번달 선택 시 `완료 8건 + 대기 3건 + 보류 1건 = 12건`이고, 완료율 분모도 12건이다. (AC8)
- 정산 예정 금액이 `3,240,000원` 형태로 표기된다. (AC9)

### 실패 (예외처리 포함)
- 탭을 빠르게 여러 번 전환 → 이전 응답이 나중에 도착해 카드 값이 뒤섞이지 않고, 마지막으로 선택한 탭의 값만 표시된다. (AC11)
- 탭 전환 중 일부 카드만 갱신되고 나머지가 이전 기간 값으로 남는 상태가 발생하지 않는다. (AC3)
- 완료율은 `100%`인데 대기/보류 건수가 0이 아닌 모순 상태가 노출되지 않는다. (AC8)
- 요약 API가 실패 → 카드가 이전 기간 값을 그대로 보여주지 않고 에러 안내가 노출된다. (AC1)
- 요약 대시보드에서 `전분기` 탭으로 전환한 뒤 정산 내역 목록 화면 확인 → 목록의 기간·상태 조건과 조회 결과가 바뀌지 않았다. (AC10)
