# 도메인: settlement (정산)

## 도메인 정책

정산 도메인 전반(모든 에픽·스토리)에 공통 적용되는 불변 규칙만 기술한다.

### 1. 정산 금액 산출 공식
```
최종 정산액 = 상품 판매액 − 플랫폼 수수료 − 조정 금액
```
- **상품 판매액**: 해당 정산 기간 동안 확정된 판매 금액 합계.
- **플랫폼 수수료**: 상품 판매액 × 파트너 등급별 수수료율. 화면에는 음수(`-134,000원`)로 표기하고, 수수료율을 보조 문구로 함께 노출한다.
- **조정 금액**: 반품·환불 등으로 차감/가산되는 금액. 조정 사유를 보조 문구로 함께 노출한다. 조정 없으면 `0원`.
- 이 공식은 목록·모달·상세 페이지 어디서든 동일하게 적용되며, 화면별로 다르게 계산하지 않는다.

### 2. 금액·일자 표기 규칙
- 금액은 **원 단위 정수**로 다루며, 소수점을 쓰지 않는다.
- 화면 표기는 **천 단위 콤마 + 접미사 `원`** (예: `1,204,000원`). 로케일은 `ko-KR`.
- 차감 금액은 음수 부호를 앞에 붙여 표기한다 (예: `-134,000원`).
- 일자는 `YYYY-MM-DD` 형식으로 표기한다.

### 3. 수수료율 단일 출처
- 파트너 등급별 수수료율 및 정산 주기는 **정산 수수료율 정책 엑셀**을 단일 출처로 삼는다. 링크는 각 에픽의 `참조 자료` 참조.
- 화면·코드에 수수료율을 하드코딩하지 않는다. 캔버스의 `10%`는 예시 값이다.

### 4. 정산 상태 (3종)
| 상태 | 의미 |
|---|---|
| 대기 | 정산 대상으로 확정되었으나 아직 지급 처리되지 않은 건 |
| 완료 | 지급 처리까지 끝난 건 |
| 보류 | 확인이 필요해 지급이 멈춰 있는 건 |

- 목록 상태 컬럼(Tag), 상태 필터 체크박스, 요약 대시보드 상태별 건수, 상세 화면 모두 **이 3종을 동일한 명칭으로** 사용한다.
- 상태는 이 3종이 전부이며, 화면·에픽마다 다른 상태를 추가로 정의하지 않는다.
- (에픽 분리 전에는 에픽이 소유했으나, `epic-partner-settlement-list`와 `epic-partner-settlement-detail` 양쪽에 걸치게 되어 도메인으로 올렸다.)

### 5. 조회 주체와 데이터 범위
- 파트너는 **자신에게 귀속된 정산 건만** 조회할 수 있다. (근거: 에픽 목적 — "파트너가 CS 문의 없이 정산 상태를 스스로 파악", 대상 플랫폼 = partner)
- 정산 건은 `정산일 + 파트너`를 축으로 식별되며, 목록·상세 모두 동일한 정산 건 ID를 참조한다.

### 6. 디자인 시스템 재사용 원칙
- 이 도메인의 파트너/어드민 화면은 `design-system/admin-partner/src/components/{카테고리}/{컴포넌트명}`의 기존 컴포넌트를 **import해서 사용한다. 새로 만들지 않는다.**
- 통합캔버스의 `<!-- component: X -->` 태깅은 그대로 신뢰한다.
- 기존 컴포넌트로 표현할 수 없는 요소는 캔버스의 "디자인 시스템 미보유" 항목으로 **사실만 기록**되어 있다. **디자인 시스템을 손대는 작업(신규 추가·variant 추가·공용화)은 애자일 이슈의 태스크 범위가 아니다** — 디자인 시스템 트랙에서 별도로 처리한다. 단 **화면 영역까지 보류하는 것은 `신규 필요` 한 가지뿐**이고, `variant 값 추가 필요`·`참조 전용(page-local)`·`공용화 필요`는 컴포넌트가 이미 존재하므로 화면 구현 AC·태스크·테스트를 정상적으로 둔다(agile-issue-rule.md 「태스크 범위에서 제외되는 작업 — 디자인 시스템」).
- 태깅이 누락된 요소를 발견하면 임의로 구현하지 않고 질문한다.

## 하위 에픽
- epic-partner-settlement-list: 파트너가 정산 내역을 기간·상태로 조회하는 목록 조회 기능
- epic-partner-settlement-summary: 파트너가 기간별 정산 규모와 처리 현황을 한눈에 확인하는 요약 대시보드
- epic-partner-settlement-detail: 파트너가 건별 정산 금액의 산출 근거를 확인하고 내역서를 내려받는 상세 조회 기능
