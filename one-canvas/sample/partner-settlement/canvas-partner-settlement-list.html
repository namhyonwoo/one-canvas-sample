에픽

에픽epic-partner-settlement-list (파트너 정산 내역 조회)
목적파트너가 CS 문의 없이 자신의 정산 진행 상황을 스스로 파악할 수 있게 하여 CS 문의량을 줄인다.
주요 범위 (In-Scope)정산 내역 목록 조회(기간·상태 필터), 적용된 필터 표시
제외 범위 (Out-of-Scope)정산 현황 요약 대시보드(canvas-partner-settlement-summary.html 로 분리), 건별 상세 산출 근거 확인(canvas-partner-settlement-detail.html 로 분리), 정산 금액 수정 및 이의 신청 접수(canvas-partner-settlement-detail.html 제외 범위 참조)
완료 기준파트너가 기간·상태로 정산 내역을 조회하고, 적용된 조건을 확인하며 페이지를 넘겨 전체 결과를 볼 수 있어야 한다.

유저스토리

  • story-settlement-search (파트너가 기간별로 정산 내역을 검색한다)
    • Given 정산 내역이 있는 파트너가 조회 화면에 있고, When 시작일·종료일을 선택해 검색하면, Then 해당 기간의 정산 내역만 목록에 표시된다.
    • Given 선택한 기간에 정산 내역이 없고, When 검색하면, Then 목록 대신 결과 없음 안내를 보여준다.
  • story-settlement-filter (파트너가 정산 상태로 내역을 필터링한다)
    • Given 정산 내역 목록이 표시된 상태에서, When 정산 상태(대기/완료/보류) 필터를 선택하면, Then 해당 상태의 내역만 목록에 남는다.

UI 디스크립션 — settlement-list (정산 내역 조회)

  1. 1
    조회 조건 — 기간(DateRangePicker)과 상태(Checkbox: 대기/완료/보류, 다중 선택)를 조합해 조회 버튼을 누르면 목록이 갱신된다.
    DateRangePicker inputs-daterangepicker--default Checkbox inputs-checkbox--default Button(variant=primary) inputs-button--primary
  2. 2
    적용된 필터 — 현재 조회에 사용된 조건을 FilterChip으로 보여준다. × 클릭 시 해당 조건만 해제하고 즉시 재조회된다.
    FilterChip inputs-filterchip--chip-group
  3. 3
    정산 내역 테이블 — 행을 클릭하면 해당 건의 정산 상세가 열린다. 상세 화면·정책은 canvas-partner-settlement-detail.html 이 소유한다.
    Table 스토리 없음 Tag display-tag--default
  4. 4
    페이지네이션 — 조회 결과가 3건을 초과하면 노출되며, 페이지 전환 시 테이블 내용만 갱신된다.
    Pagination display-pagination--default

디자인 시스템 미보유: 없음 — DateRangePicker, Checkbox, Button, FilterChip, Table, Tag, Pagination 모두 기존 design-system/admin-partner 컴포넌트로 구성.
